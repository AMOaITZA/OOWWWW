# El video de nuestra tele

Coloca aquí tu video con el nombre exacto **`nuestro-video.mp4`**.

Ruta desde la raíz del proyecto:

`assets/game/home/videos/nuestro-video.mp4`

Se recomienda MP4 con video H.264 y audio AAC para que funcione en Chrome,
Android y Safari/iPhone. También se admite `nuestro-video.webm`; si hay ambos,
se elige el MP4.

Después de copiar el archivo, reinicia `npm run dev`. Para publicar una nueva
compilación, vuelve a ejecutar `npm run build`. No hay que editar código ni JSON.

Entra en **Nuestra casita → Ver la tele → Reproducir video**. El video no se
reproduce automáticamente al abrir la casa. Se puede pausar, silenciar y ver
en grande. Al cambiar de actividad o cerrar se detiene y conserva su posición.

Esta carpeta solo contiene instrucciones hasta que añadas tu video. Los videos
temporales utilizados por las pruebas se eliminan y no forman parte del juego.
